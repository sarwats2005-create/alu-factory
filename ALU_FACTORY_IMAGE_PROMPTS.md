## TIPS FOR BEST RESULTS

**Midjourney specific additions to append:**
- For photorealistic UI: `--style raw --v 6`
- For widescreen dashboard: `--ar 16:9`
- For mobile screens: `--ar 9:19.5`
- For square assets (logo, icon): `--ar 1:1`
- Quality boost: `--q 2`

**General tips:**
- If the result is too decorative, add: `no gradients, no decorations, no illustrations, minimal`
- If you want darker UI, add: `dark mode, dark background`
- If you want lighter UI, add: `light mode, white background, clean`
- Run each prompt 4 times and pick the best — slight variations will give you options to choose from
